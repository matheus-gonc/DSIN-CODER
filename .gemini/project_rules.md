# Diretrizes de Commits do Projeto

- Os commits serão sempre realizados manualmente pelo usuário/operador.
- Sempre que houver uma alteração com um volume relevante de arquivos em um prompt (ou funcionalidades expressivas), fornecer ao final da resposta:
  - **Título do commit** (formato semântico/padronizado).
  - **Descrição detalhada** explicando as alterações realizadas.
